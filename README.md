# Silver Escapes

A travel and itinerary planning platform built using Django.

## Features
- User Authentication
- Destination Explorer
- Personalized Itinerary Planner
- Wishlist
- Hotel Recommendations
- Profile Management
- Contact Form
- Password Reset via Email

## Tech Stack

- Python
- Django
- HTML
- CSS
- JavaScript
- PostgreSQL (Neon)
- Cloudinary
- WhiteNoise
- Vercel
